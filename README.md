# Taste Match

Taste Match recommends one movie based on three books, songs, or artists you love, and explains why it fits. It is built for young "media snobs" (around 22-27) who care a lot about books and music and are tired of genre-based suggestions.

## Working prototype

https://taste-match-finder.replit.app

Open the link, enter three favorites, and click "Find my movie." No login is needed, and no API key is stored in this repository because the app calls OpenAI through Replit's managed AI integration.
